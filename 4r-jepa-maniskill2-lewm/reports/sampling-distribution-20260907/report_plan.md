# 采样分布审计报告计划

- 问题：当前带噪启发式采样是否过于顺利或单一，已有数据能支持何种世界模型学习结论？
- 读者：实现与训练负责人；此报告以测量定义、覆盖诊断和训练分布风险为主，采用 technical-report 结构。
- 交付：离线可打开的便携 HTML，canonical `artifact.json` 经插件 `npm run report:deliver` 生成；不发布网站，不访问 GPU 或仿真。
- 证据：由主分析脚本固定 Lance snapshot 后生成的汇总和抽样表；精确版本、时间、表名、过滤与分母均从实际输出读取。
- 结论边界：顺滑抓起不等于完整覆盖；行为多样性也不能直接证明表征泛化。区分描述统计、代理指标和未被数据支持的质量结论。

## 结构映射

1. 标题及独立技术摘要：先回答是否单一，给出已核实的关键数字及不可作出的判断。
2. 指标口径先行：固定快照、完整回合、帧/回合分母、抬起/接近/到目标/静止成功的区别。
3. 行为结果：条形图比较有意义的回合类别或事件发生率，避免把重叠事件画成互斥组成。
4. 状态覆盖：空间散点、二维聚合或高度直方图；显示分布形状，绝不凭 min/max 称覆盖充分。
5. 动作与困难过程：按实际可支持的动作分布、接近/夹持/搬运/掉落等代理指标描述。
6. 方法、限制与稳健性：固定版本与确定性抽样；缺失标签、contact 不可重建、阈值敏感性、相关帧与独立回合的区别。
7. 下一步及待解问题：指出实际缺少的状态/动作区域和评估需要，不自行改变正在运行的采样分布。

## 图表合同

- 比例比较用横向条形图，从 0 起；每行保留计数、分母、阈值和 cohort。分类过少时用卡片或精确表，不虚构类别。
- 覆盖形状用直方图/二维聚合/散点；散点样本至少 20 个等粒度观测，确定性选择并声明全量/抽样差异。
- 不用平滑抓取视频当总体代表，不用无关装饰折线，不对没有接触标签的状态做确切抓稳判断。
- 单系列采用蓝色单色根及中性色；多系列只在真实分组维度有意义时编码，标签和图例可辨。
- 每张图可切换到审阅后的数据表，旁附解释、分母、单位和限制。

## 不重复呈现的审计材料

计算代码与 notebook 由主分析保存；source 元数据记录文件和真实 Lance 表/版本。报告正文只保留会改变读者结论的方法和限制，不另造无效来源。
